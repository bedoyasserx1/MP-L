# 🎤 Marwan Pablo — Father of the Trap

A fan-made website dedicated to **Marwan Pablo**, one of the most influential artists in the Egyptian trap scene.

The website presents a simple visual journey through Pablo's music, career, albums, and different stages of his artistic journey.

## 🌐 Live Demo

👉 [Visit the Live Website](https://bedoyasserx1.github.io/pablo-website/)

---

## 📖 About The Website

This project was created as a personal web development project inspired by Marwan Pablo's music and artistic style.

The goal was to build a clean and modern website that presents information about Pablo in a simple and visually appealing way.

The website includes information about his musical journey, important releases, social platforms, and other related content.

---

## 🛠️ Technologies Used

### HTML5

HTML was used to build the structure and content of the website.

It was used for:

- Creating the main page structure
- Adding headings and paragraphs
- Adding images
- Creating links
- Organizing different sections
- Adding navigation links
- Structuring the website content

### CSS3

CSS was used to design and style the entire website.

It was used for:

- Colors and backgrounds
- Fonts and typography
- Text positioning
- Spacing and margins
- Image sizing
- Layout and alignment
- Borders and styling
- Hover effects
- Responsive design
- Creating a clean and modern visual appearance

---

## 🎨 Design

The design was inspired by the dark and minimal aesthetic commonly associated with the trap music scene.

The website focuses on:

- Dark visual style
- Clean typography
- Large artwork
- Simple navigation
- Modern spacing
- Music-inspired visual elements

---

## 📱 Responsive Design

The website was designed with different screen sizes in mind, allowing the layout to adapt to different devices such as:

- 💻 Desktop
- 💻 Laptop
- 📱 Mobile
